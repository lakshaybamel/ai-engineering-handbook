# Mathematics for AI/ML

Mathematics is the foundation of Artificial Intelligence and Machine Learning.

It helps us:
- understand data
- measure uncertainty
- represent information
- optimize models

This module covers only the **essential math required for AI/ML** (not deep theoretical math).

---

# Why Mathematics is Important

Machine Learning is not just coding — it is applied mathematics.

Used in:
- probability → uncertainty handling
- statistics → data understanding
- linear algebra → data representation
- calculus → optimization
