# Introduction to Data Visualization

Data Visualization is the process of representing data graphically so humans can understand patterns, trends, and relationships quickly.

Raw numbers are difficult to interpret.
Graphs convert numbers into meaning.

---

## Why Visualization Matters

Machine Learning models are built on data, but before modeling we must understand:

- distribution of values
- outliers
- trends over time
- relationships between variables

Visualization is the fastest way to explore this.

---

## Example

Instead of reading:

Temperature = [22, 23, 25, 27, 30, 31, 29]

A line plot immediately shows rising trend.

Humans understand visuals faster than tables.

---

## Types of Analysis Done Using Visualization

| Purpose | Plot Type |
|------|------|
Trend over time | Line plot |
Comparing categories | Bar chart |
Relationship between variables | Scatter plot |
Distribution | Histogram |
Proportion | Pie chart |
Spread & Outliers | Box plot |

---

## Visualization in Data Science Workflow

Data Collection → Cleaning → **Visualization** → Feature Engineering → Modeling

Visualization helps decide:

- which features matter
- whether data is usable
- if preprocessing is required

---

## Tools Used

We will use:

Matplotlib → low level plotting (full control)  
Seaborn → statistical plotting (simpler & prettier)

---

## Key Idea

Visualization is not decoration.

It is a decision-making tool.

A good graph answers a question instantly.
