# Data Visualization

Data Visualization is the bridge between raw data and understanding.

In the AI/ML workflow, visualization helps:
- detect patterns
- identify anomalies
- understand distributions
- validate preprocessing
- communicate insights clearly

This module covers both:

• Matplotlib (low-level control)  
• Seaborn (high-level statistical visualization)
