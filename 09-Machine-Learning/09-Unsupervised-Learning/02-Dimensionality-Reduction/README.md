# 📉 Dimensionality Reduction

## 📌 Overview

Dimensionality Reduction is the process of reducing the number of input features while preserving important information.

👉 Helps simplify data without losing key patterns

---

## 🧠 Core Idea

> Reduce number of features while keeping maximum useful information

## ⚙️ Why Dimensionality Reduction?

* Reduces computational cost
* Removes redundant features
* Improves model performance
* Helps visualize high-dimensional data

---

## 🔷 Types of Dimensionality Reduction

### 1. Feature Selection

* Select important features
* Example: removing irrelevant columns

---

### 2. Feature Extraction

* Create new features from existing ones
* Example: PCA

---

## 🔷 Workflow

```text
High-Dimensional Data
   ↓
Feature Scaling
   ↓
Apply PCA
   ↓
Select Components
   ↓
Reduced Data
```

---

## 🔷 Advantages

* Faster training
* Less storage
* Reduces overfitting
* Improves visualization

---

## 🔷 Limitations

* Information loss possible
* Reduced interpretability
* Needs preprocessing

---

## ⚠️ Important Points

* Always scale data before PCA
* Choose components carefully
* Balance between accuracy and reduction
