# 🌳 Tree-Based Models

## 📌 Overview

Tree-Based Models are machine learning algorithms that make decisions by splitting data into smaller subsets using a tree-like structure.

They are widely used for both:

- Classification  
- Regression  

---

## 🧠 Key Idea

> Recursively split data based on feature values to reduce impurity

---

## 🔗 Topics Covered

### 1. Decision Trees

- Entropy & Gini (impurity measures)  
- Information Gain  
- Pruning techniques  
- Classification & Regression  

📂 Folder: [`Decision-Trees`](./Decision-Trees/)

---

## ⚙️ Workflow

```
Start with full dataset
        ↓
Choose best feature to split
        ↓
Create branches (subsets)
        ↓
Repeat recursively
        ↓
Stop when pure or criteria met
```

---

## 🎯 Where It is Used

- Loan approval systems  
- Customer segmentation  
- Medical diagnosis  
- Fraud detection  

---

## ⚠️ Important Points

- Easy to interpret and visualize  
- Handles non-linear relationships  
- No feature scaling required  
- Prone to overfitting
