# 🧠 Instance-Based Learning

## 📌 Overview

Instance-Based Learning is a type of machine learning where the model **stores training data** and makes predictions based on **similarity between data points**.

---

## 🧠 Key Idea

> Learn from examples by comparing new data with existing data

---

## 🔗 Topics Covered

### 1. K-Nearest Neighbors (KNN)

- Distance-based algorithm  
- Lazy learning approach  
- Uses nearest neighbors for prediction  

📂 Folder: [`KNN`](./KNN/)

---

## ⚙️ Workflow

```
Store Training Data
    ↓
Receive New Data Point
    ↓
Find Similar Data Points
    ↓
Make Prediction
```

---

## 🎯 Where It is Used

- Recommendation systems  
- Pattern recognition  
- Image classification  

---

## ⚠️ Important Points

- No explicit training phase  
- Prediction can be slow  
- Sensitive to scaling and noise
