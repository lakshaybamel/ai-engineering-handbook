# 🧠 Probabilistic Models

## 📌 Overview

Probabilistic models are machine learning algorithms that make predictions based on **probability theory**.

They estimate the likelihood of different outcomes and choose the most probable one.

---

## 🧠 Key Idea

> Predict outcomes using probability distributions

Instead of directly predicting values, these models compute:

- Probability of each class  
- Select the class with highest probability
