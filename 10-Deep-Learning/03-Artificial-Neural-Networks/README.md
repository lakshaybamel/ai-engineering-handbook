# 🧠 Artificial Neural Networks (ANN)

Artificial Neural Networks (ANNs) are one of the fundamental models used in **Deep Learning**.
They are inspired by the structure of the **human brain**, where interconnected neurons process information and learn patterns from data.

ANNs can model **complex relationships between input features and outputs**, making them powerful for many machine learning tasks such as regression and classification.

In this section, we implement neural networks using **PyTorch** to understand how deep learning models are built and trained.
