# 🧠 Artificial Neural Network (ANN) for Classification

This section demonstrates how to build and train an **Artificial Neural Network (ANN)** to solve a **classification problem** using **PyTorch**.

The goal of this example is to classify different **types of date fruits** based on numerical features extracted from the dataset.

This module walks through the **complete workflow of training a neural network for classification**, including:

* building the neural network architecture
* training the model
* evaluating classification performance
