# 📂 Projects Included

## 🖼️ CIFAR-10: CNN vs Logistic Regression

🔗 https://github.com/lakshaybamel/cifar10-cnn-vs-ml-comparison

### 📌 Description

Comparison between traditional machine learning and deep learning for image classification.

### 🛠️ Tech Stack

* PyTorch
* Scikit-learn
* torchvision

### 🎯 Concepts Used

* Logistic Regression vs CNN
* Feature extraction vs spatial learning
* Model comparison

### 📈 Results

* Logistic Regression: ~33%
* CNN: ~70%

👉 CNN significantly outperforms traditional ML due to spatial understanding.

## 🔢 MNIST: ANN vs CNN

🔗 https://github.com/lakshaybamel/mnist-ann-vs-cnn

### 📌 Description

Comparison between ANN and CNN on handwritten digit classification.

### 🛠️ Tech Stack

* PyTorch
* NumPy
* Matplotlib

### 🎯 Concepts Used

* ANN vs CNN
* Image representation
* Performance comparison

### 📈 Results

* ANN: ~96–97%

👉 CNN performs better due to spatial feature learning.

## 📊 Customer Churn Prediction (ANN)

🔗 https://github.com/lakshaybamel/customer-retention-prediction

### 📌 Description

Predict customer churn using structured banking data.

### 🛠️ Tech Stack

* PyTorch
* Pandas
* Scikit-learn

### 🎯 Concepts Used

* Data preprocessing
* Feature encoding & scaling
* Handling class imbalance
* ANN for tabular data

### 📈 Results

* Accuracy: ~70–72%
* Recall: ~73–75%

### 🧠 Key Insight

👉 Deep Learning is not always best for tabular data (tree models often perform better).

## 🧠 Sentiment Analysis (LSTM – IMDB)

🔗 https://github.com/lakshaybamel/sentiment-analysis-lstm-imdb

### 📌 Description

Classify movie reviews as positive or negative using LSTM.

### 🛠️ Tech Stack

* PyTorch
* NLTK
* NumPy

### 🎯 Concepts Used

* Text preprocessing
* Tokenization & padding
* LSTM networks
* Sequence learning

### 📈 Results

* Accuracy: ~88%

### 🔍 Key Learnings

* LSTM captures sequential dependencies
* Works well for text data
* Being replaced by transformers in modern NLP
