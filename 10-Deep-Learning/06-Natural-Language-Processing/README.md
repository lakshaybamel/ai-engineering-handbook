# 🧠 Natural Language Processing (NLP)

## 📌 Overview

**Natural Language Processing (NLP)** is a branch of **Artificial Intelligence (AI)** that focuses on enabling machines to **understand, analyze, and generate human language**.

Unlike numerical data, text data is **unstructured**, meaning it cannot be directly used by machine learning models.
Therefore, NLP techniques are used to **clean, process, and convert text into numerical representations**.

These processed representations can then be used by **machine learning and deep learning models** to perform various language-related tasks.

In this section, we explore the **fundamental concepts of NLP and text preprocessing techniques** used before training neural network models.
