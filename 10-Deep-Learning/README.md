# 🤖 Deep Learning

Deep Learning is a subset of **Machine Learning** that uses **neural networks with multiple layers** to learn complex patterns from data.

It is widely used in:

* computer vision
* natural language processing
* speech recognition
* recommendation systems

This repository documents my journey of learning Deep Learning with **theory + implementations + projects**.

---

# 🧠 Core Idea

```text
Input Data → Neural Network → Learning → Prediction
```

Deep Learning models automatically learn **features and patterns** from data without manual feature engineering.
