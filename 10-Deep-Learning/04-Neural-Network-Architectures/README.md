# 🧠 Neural Network Architectures

## 📌 Overview

Neural Network Architectures define **how neurons are organized and connected inside a neural network**.

Different architectures are designed to handle different types of data and learning tasks.
The structure of the network determines **how information flows and how patterns are learned**.

Understanding neural network architectures is important because it helps us choose the **right model for a specific problem**.

---

# 🧩 Feedforward Neural Network (FNN)

📄 [feedforward_neural_network.md](feedforward_neural_network.md)

The **Feedforward Neural Network** is the most basic and widely used neural network architecture.

In this architecture, information flows **only in one direction**:

```text
Input Layer → Hidden Layers → Output Layer
```

There are **no loops or feedback connections**, which makes the model simple and easy to understand.

Topics covered:

* structure of feedforward networks
* input, hidden, and output layers
* forward propagation
* example neural network architecture
* advantages and limitations

Feedforward networks serve as the **foundation for many deep learning models**.
