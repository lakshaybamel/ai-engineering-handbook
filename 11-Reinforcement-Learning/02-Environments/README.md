# 🌍 Reinforcement Learning Environments

Environments define the **world in which the agent interacts, takes actions, and receives rewards**.

In Reinforcement Learning, the environment plays a crucial role because:

* it defines the **states and transitions**
* it provides **rewards and penalties**
* it determines how the agent learns optimal behavior
